# ヒーローイメージとキャッチコピー 要件定義

作成: 2026-08-10 / 対象: 浜通りクエスト（ベータ公開 2026-10 予定）

この文書は **デザイナーへの依頼書** です。何を作るか、どんな制約があるかを書いています。
図案の中身は決めていません。そこは提案していただく前提です。

---

## 1. サービスの前提（30秒で読める分）

浜通りクエストは、**福島県浜通りを歩いて回ってもらうためのスマホ向けWebアプリ**です。

- イベント会場や飲食店に **QRコードを貼っておき、読み取るとポイントが入る**
- 地図にスポットのピンが立つ。回った数と獲得ポイントが記録される
- SNSのフォローや投稿でもポイントが入る
- LINEでログインする。アカウント登録はLINEのみ

ハマフェス（2026年10月予定）をきっかけに使ってもらうことを想定しています。

**注意**: このアプリは政治団体のオープンソース（チームみらい「アクションボード」）を
派生元にしています。**画面や素材に派生元の名残があり、それを消す作業の一部がこの依頼です。**
政治・選挙・政策に関する語や、派生元の青緑（#30bca7）は使えません。

## 2. 決まっている方向（2026-08-10 合意）

| 論点 | 決定 |
|---|---|
| 誰に向けるか | **域内の住民と域外からの来訪者の両方**。どちらでも読める語にする。絵で場所を特定しすぎない |
| 世界観 | **実在の浜通りの風景を主に**。「クエスト」感はピンや宝箱などの小さな記号で添える程度 |
| 人の扱い | **地域の人々を描く**。現行と同じ「背景＋前景の人物」の2枚重ね構成を維持する |
| コピーの軸 | **回ること自体の楽しさ**。歩いて、読み取って、集まっていく感覚 |

RPG寄りの絵にしない理由: 実在の店やイベント会場を回る仕組みなので、絵と実際の体験が
乖離すると期待外れになります。地図・巻物・剣のような記号は主役にしません。

## 3. 納品物

### 3-1. 画像（2点）

| # | 内容 | ファイル名 | サイズ | 形式 |
|---|---|---|---|---|
| A | 背景（風景・街並み・空） | `hero-background.svg` | **1080 × 560 px** | SVG |
| B | 前景（人物） | `hero-people.svg` | **382 × 224 px** | SVG |

- **2枚は重ねて表示します。** Aが後ろ、Bが手前。どちらも**下端を基準に配置**されます
- Bは横幅が狭い（382px）ことに注意。**画面中央に人物が集まる構図**になります
- 既存ファイルを差し替える形なので、**ファイル名とサイズは変えないでください**
- 既存の2点は参考として添付します（青緑のもの）。構図の踏襲は不要です

### 3-2. コピー（1本＋任意）

| # | 内容 | 分量 | 必須 |
|---|---|---|---|
| C | キャッチコピー（ヒーローに表示） | **全角30字以内**（推奨20字前後） | 必須 |
| D | サイト説明文（検索結果とSNSに出る） | **全角60〜90字** | 必須 |
| E | 略称・呼びかけの語 | 数文字 | 任意 |

CとDは別物です。詳細は 5 章。

## 4. 画像の制約（ここが重要）

### 4-1. SVGで納品してください

理由: 拡大に強く、ファイルが軽く、後から色だけ変えられる可能性が残ります。

**ただし色の扱いに注意点があります。** SVGの塗りは色の値として書き出されるため、
アプリ側の配色設定（CSS変数）では変えられません。
現行の2点は**青緑 #30bca7 が72箇所に直接書かれており、色を変える手段がない**状態です。

お願い:
- **同じ色は同じ値で**書き出してください（微妙に違う値が散らばると後から一括変更できません）
- 色数は**5〜8色程度**に抑えてください
- 使った色の一覧（16進数）を添えてください
- 文字（テキスト要素）は入れないでください → 4-4

### 4-2. 中央の上半分は空けてください

ヒーローの上に、HTMLで以下が重なります。**絵で埋めないでください。**

```
画面上端
  ↓  96px    ヘッダー（白い帯）が重なる
  ↓ 120px    ロゴ画像（中央）
  ↓          見出し「浜通りクエスト」（中央・大きめ）
  ↓          キャッチコピー（中央・小さめ太字）
  ↓          ボタン「浜通りクエストに登録する」（中央・角丸）
  ↓          リンク「浜通りクエストとは？」
画面下端      ← このあたりに人物と街並みが来る
```

- セクション全体の高さは **740px 固定**
- 情報は**中央に縦一列**で並びます。左右に余白があるので、**絵の見せ場は左右と下**です
- 背景の**上部は空（そら）**として扱ってください。文字が乗っても読める明るさで

### 4-3. 同じ2枚をフッターでも使い回します

トップページだけでなく、**全ページのフッター上部にも同じ2枚が出ます**。

| 使う場所 | 背景の表示サイズ | 人物の表示サイズ |
|---|---|---|
| トップページ（未ログイン） | 幅 1080px / 高さ 560px | 幅最大1080px / 高さ 224px |
| フッター（全ページ・全ユーザー） | 幅最大 756px / 高さ 392px | 幅最大 756px / 高さ 157px |

フッターでは**7割程度に縮む**ので、細い線や小さな描き込みは潰れます。
**縮小しても形が読める密度**にしてください。

### 4-4. 絵の中に文字を入れないでください

キャッチコピーも見出しもHTMLで表示しています。絵に文字を焼き込むと、
文言を直すたびに絵を作り直すことになります。看板や標識を描く場合も、
**読める文字は入れない**（記号や図形として処理する）でお願いします。

### 4-5. スマホでの見え方

- 背景は**1080px幅の固定**で中央基準に置かれます。**狭い画面では左右が切れます**
- したがって、**画面端に重要なモチーフを置かないでください**
- 検証は iPhone 幅（390px）で行います。この幅では背景の中央36%程度しか見えません

### 4-6. 配色

現在のブランド色（浜通りサークルのロゴ由来の黄色）です。

| 用途 | 値 |
|---|---|
| 主色（黄） | `#ffea00` |
| 濃い黄（文字・線） | `#ffd400` / `#b38f00` |
| 淡い地色 | `#fffbe6` |
| ヒーローの背景グラデーション | 上 `#ffea00` → 下 `#fffbe6`（**CSSで描くので絵には不要**） |

- 絵の背景は**透明**にしてください。上記のグラデーションが後ろに敷かれます
- **青緑系（#30bca7 / #0f8472 / #bcecd3）は使わないでください。** 派生元の色です
- 黄色一色だと平板になるので、海の青や緑は使って構いません。**青緑（ティール）だけを避ける**という意味です

### 4-7. 描く対象の候補（例示。指定ではありません）

浜通りらしさが伝わり、かつ特定の市町村に寄りすぎないもの。

- 海と水平線、堤防、朝の光
- 国道6号・常磐線、車窓
- 道の駅、商店、のれん、屋台
- 田畑と里山、松林
- 祭りの気配（提灯、櫓）

「復興」を主題にしないでください。**いま暮らしていて、いま楽しい場所**として描いてください。

## 5. コピーの要件

### 5-1. C: キャッチコピー（ヒーローに表示）

**現在の文言（派生元のまま。これを置き換えます）**

> テクノロジーで政治をかえる。あなたと一緒に未来をつくる。

要件:

- **全角30字以内。** 推奨20字前後（スマホで2行に収まる長さ）
- 見出し「浜通りクエスト」の**すぐ下に置かれる**ので、名前と重複する説明をしない
- **回ること自体の楽しさ**が伝わること（歩く・読み取る・集まる）
- 域内の人にも域外の人にも読めること。「来てください」に寄せすぎない
- 音読して引っかからないこと（**語呂・リズムを重視**）
- **3案以上**、それぞれ「何を狙ったか」を1〜2行添えてください

**使えない語**

政治 / 選挙 / 政策 / マニフェスト / 投票 / サポーター（政治団体の支持者を指す語）

「未来をつくる」のような言い回しは、派生元の団体名（チームみらい）を想起させるため
避けたいです。「未来」という語自体を禁じる意図ではありません。

**方向のたたき台**（そのまま使う前提ではありません。幅を示すためのものです）

- 「歩いた分だけ、浜通りが増えていく。」— 回るほど自分の地図が埋まる感覚
- 「読み取るたびに、知らない浜通り。」— QRという仕組みを楽しさに翻訳
- 「この道の先に、まだ知らない浜通り。」— 域内の再発見と域外の来訪の両方に効く

### 5-2. D: サイト説明文

**検索結果とSNSのサムネイルに出る文章**です。ヒーローのコピーより多くの人が目にします。

**現在の文言（置き換えます）**

> 政治活動をもっと身近に。楽しく政治参加に取り組める、浜通りクエスト。

要件:

- **全角60〜90字**
- 「何をするアプリか」が1文で分かること（回る・読み取る・ポイントが貯まる）
- 検索から来た人が読む文章なので、**世界観よりも具体性**を優先
- Cと矛盾しないこと

### 5-3. E: 略称・呼びかけ（任意）

「浜通りクエスト」は7文字あり、会話では略されます。**自然に略せる形かどうか**を見てほしいです。

- 略称を作るなら候補を出してください（例: ハマクエ）
- **ハッシュタグは `#浜通りクエスト` で既に実装済み**です。変えるなら別途調整が必要なので、
  変更を提案する場合は理由を添えてください
