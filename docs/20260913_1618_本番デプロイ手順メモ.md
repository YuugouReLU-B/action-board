# 本番デプロイ手順メモ

## 背景

`AGENTS.md` に記載の通り、`.github/workflows/deploy.yml`（`develop`/`main` へのpushで自動起動する
「Migrate DB then Deploy」）は、このフォーク（`YuugouReLU-B/action-board`）では**Secrets/Variablesが
一つも設定されておらず機能していない**（2026-08-08以降の全実行が最初の「Link Supabase project」で失敗）。

そのため、本番反映は現状すべて手動で行う必要がある。2026-09-13時点で判明している手順を残す。

## フロントエンド（Vercel）

- Vercelプロジェクト: `yuugouohnos-projects/hamadori-quest`（本番URL: https://hamadori-quest.vercel.app）
- **Gitリポジトリとの連携（Vercelの自動デプロイ）は行っていない**（`vercel.json` で `main`/`develop` 両方
  `deploymentEnabled: false` にしてあるのに整合）。デプロイは常にCLIから手動実行。
- 本番用の環境変数（`NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `BASIC_AUTH_USER/PASSWORD` 等）
  はVercel側（Production環境）に設定済み。ローカルの `.env` とは別物。

### 手順

```bash
# 初回のみ: このディレクトリをVercelプロジェクトに紐付ける
npx vercel link --yes --project hamadori-quest --scope yuugouohnos-projects

# 本番デプロイ（developの内容を反映したいときは、事前にそのブランチ/コミットをcheckoutしてから実行）
npx vercel --prod --yes
```

- `vercel link` を実行すると `.vercel/`（プロジェクト紐付け情報）と `.env.local`（`VERCEL_OIDC_TOKEN`）が
  生成される。どちらもgitignore対象（`.vercel` は元から、`.env.local` は既存の `.env*.local` ルールで対象）。
  **`vercel link` はなぜか `.gitignore` に `.env*` という行を追記することがある**（既存の
  「`.env*.local` に絞っている」という意図を上書きしてしまう）。実行後は `git diff .gitignore` を確認し、
  意図しない追記があれば `git checkout -- .gitignore` で戻すこと。
- サイト全体に公開前のBasic認証がかかっている（`BASIC_AUTH_USER`/`BASIC_AUTH_PASSWORD`、Vercel側で設定）。
  デプロイ自体が成功していれば `curl` では401が返るのが正常。

## データベース（Supabase本番）

- **この環境には本番Supabaseへの認証情報（`SUPABASE_ACCESS_TOKEN` / プロジェクトref / DBパスワード）が
  存在しない。** そのため、マイグレーションの本番適用はこのセッションからは実行できなかった。
- 新しいマイグレーションを追加した場合、フロントエンドを `vercel --prod` でデプロイしても
  **本番DBには反映されない**。誰か（ユーザー本人など、本番Supabaseの認証情報を持つ人）が
  別途 `supabase link --project-ref <ref> --password <db-password>` → `supabase db push --include-all`
  を実行する必要がある。
- `posting:sync` / `season:sync` も同様に、本番へは自動反映されない。手動で本番向けの環境変数を使って
  `pnpm run posting:sync` / `pnpm run season:sync` を実行する必要がある。

- `npx vercel --prod --yes` でフロントエンドは本番デプロイ済み（`https://hamadori-quest.vercel.app` に反映）。
- **`lottery_settings` テーブルのマイグレーションは本番Supabaseには未適用**。フロントエンドのコードは
